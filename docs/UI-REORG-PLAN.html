Your Community Communications: UI and menu reorganisation plan

Built (2026-11-18): phases 1 to 7 are in the app (see UPDATES.md and the "As built" notes at the end). The plan below is kept as the record of what was decided. Based on the code as it was then (0.1.459238).

Kept as rules throughout:

  • Simple modes keep the full map.
  • Advanced and Region features (today's Specialised menus) stay off by default and travel in the setup QR code.
  • Terminology: Anchored = any device on stable power (mains). It is a power setting, not a role. The internet relay is the Cloud Server.
  • Android 4.1 compatible (plain Java, no AndroidX, dialogs and drawn icons that work on old phones).
  • The device role can be changed later and travels in the setup QR code.

1.6 Setup wizard (now)

  1. Welcome: callsign and units.
  2. Voice: burst mode (explains burst vs live).
  3. Quick set from a QR code (skips most of the rest).
  4. "Advanced or simple" explanation.
  5. "How will you use it?": Advanced, Intercom, Scouts, Staff, 4WD, Friends convoy, Caravan / camping.
  6. Advanced: Public key, then "What is your group for?" (quick map point profile), then "Set up your group" (DRYAD). Simple / intercom: the group's private key, then Public key (simple) or Settings PIN (intercom).

  8. Once afterwards: Keep the app on screen (black screen), Record all voice (with catch-ups).

1.7 Phone setup QR code (now)

"YCCSETUP1|" + JSON: name (LAN store name), url / user / pass (LAN storage login), tunnel / tkey (bridge tunnel), vps / vkey / rmode / mrange / mrole (internet relay and role on or off the MANET), pub (Public key), chA (channel A), omg / omh (OpenMANET), home (home screen), defaults, menus (Specialised menus), burst, prof (quick profile), team / code / area (channel array team). Cloud groups have their own link / QR (YCCCLOUD1), and the Relay admin code is YCCADMIN1.

What's missing today: no device role in the wizard or the setup QR. The Intercom mode stands in for one role, the tablet commander view only depends on the screen size, and gateway, camera and TV setups are spread across Settings pages.

Migration rules: never change a user's existing choices silently; role defaults apply only when a role is picked in the wizard or Settings > Me, with a "these will change" list to confirm. A setup QR applies everything without asking (decision 7). Setup QR codes from older apps still work.

Risks:

  • Muscle memory: people who know today's menus. Keep the old paths for a release, and say "moved to …" where something moved.
  • Settings layout is one large XML. Moving rows must keep the ids and listeners (risk of a tick that stops saving).
  • Small screens and Android 4.1: the More screen and wizard pages must fit 480×854 and use no new APIs.
  • Role defaults could fight the feature ticks or setup QR codes. Rule: the QR wins, then the user, then the role.
  • A locked callsign must still be changeable by a new setup QR (and by Clear everything), or a phone could be stuck.
  • Testing time grows with roles. Each phase tests only the roles it touches, plus an upgrade test.

7. As built (2026-11-18)

Choices made for the open questions (the plan's defaults):

  1. More screen: yes. The overflow menu is Chat, More…, Settings and Exit (plus Intercom screen and the TV items where they apply); More groups the rest and shows only what is switched on. Shortcuts and the anchor are title bar icons.
  2. Advanced vs More…: as table 3.2, with Cloud group under Advanced and Project NOMAD, ATAK items, OpenMANET and Internet audio under More…. Tunnel, Cloud Server and network interface settings stay on the Network page (they are settings, not menus) and have their guided setups under Advanced setup.
  3. nameLock locks only the callsign (not the team name or the role).
  4. Advanced setup wizards are reachable both from ticking a feature (Relay admin, Cloud group, Battery power, Channel array) and from the Advanced setup list.

Differences from the plan:

  • The radio home loses Share my location (into Shortcuts, with its state on the Shortcuts button) and the simple modes' second row of quick buttons; four quick buttons stay, picked on the Shortcuts page.
  • The map home keeps its buttons; Shortcuts is in the title bar.
  • The wizard asks the callsign first, then the QR code, then the role. The location and maps steps and the closing summary with a setup QR were left out (defaults already match; Settings > Me > Phone setup QR code makes the next device's code).
  • Advanced setup wizards are an intro (what it is, the steps) that opens the existing screen or steps.
  • Route options stay on the Alerts page (not moved into the map's Routes menu).
